# MIT-BIH research preview

1,408 fixed beats, 64 per test record, selected without using labels or predictions. Contains normalized waveforms, past-RR context, labels, record IDs, and expert sample positions. This is a record-balanced audit, not the full beat-weighted test population.

Source: MIT-BIH Arrhythmia Database v1.0.0, PhysioNet, https://physionet.org/content/mitdb/1.0.0/ . Retain attribution and the source Open Data Commons Attribution License v1.0. See docs/DATA_CARD.md.
